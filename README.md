# Kaggle Assignments

## Assignment 1: NYC Taxi Fare Prediction

**Objective:** Predict the total fare amount of New York City taxi trips using trip-related features such as distance, duration, passenger count, pickup/dropoff locations, payment type, and trip timestamps.

### Key Work

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Missing value treatment and duplicate removal
* Correlation analysis and outlier detection
* Feature engineering and visualization
* Creation of derived features such as:

  * Trip duration
  * Pickup hour
  * Day of the week
  * Fare categories

### Models Evaluated

* Linear Regression
* Ridge Regression
* Lasso Regression
* Decision Tree Regressor
* Random Forest Regressor
* Gradient Boosting Regressor
* XGBoost Regressor
* LightGBM Regressor

### Outcome

The final model was selected based on validation performance and used to generate predictions for the test dataset. This assignment provided practical experience in regression analysis, feature engineering, model evaluation, and predictive modeling on real-world transportation data.

**Kaggle Rank:** **5 / 1,383**
**Best Score:** **0.9691**

## Assignment 3: Sentiment Classification

**Objective:** Predict the sentiment of text phrases using machine learning and natural language processing techniques. The goal was to classify each phrase into its corresponding sentiment category based on its textual content and associated features.

### Key Work

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Missing value treatment
* Feature engineering
* Text vectorization using TF-IDF
* Model comparison and evaluation
* Hyperparameter tuning

### Models Evaluated

* Logistic Regression
* Multinomial Naive Bayes
* Linear SVC
* Decision Trees
* Random Forests
* Extra Trees
* KNN
* LightGBM

### Outcome

The final model, **Multinomial Naive Bayes**, achieved the best performance and was used to generate predictions on the test dataset. This assignment provided practical experience in text mining, feature extraction, model selection, and performance evaluation for natural language processing tasks.

**Kaggle Rank:** **212 / 1,309**
**Best Score:** **0.6458**
